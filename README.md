# 🐰 SSDAM-LAB 쓰담랩

https://ssdam-lab.github.io/

일상을 쓰담쓰담하는 작은 앱을 만드는 곳. 옛날 컴퓨터 바탕화면처럼 꾸민 홈페이지예요.

## 개발 일지 글 쓰는 법 (GitHub 웹에서)

1. 이 저장소에서 `_posts` 폴더를 열어요.
2. **Add file → Create new file**을 눌러요.
3. 파일 이름을 `날짜-영어제목.md`로 지어요. 예: `2026-11-12-damnote-v2-4.md`
4. 내용을 아래처럼 적어요.

```
---
title: 여기에 글 제목
tags: [담노트]
---
여기부터 본문이에요. 그냥 메모하듯 쓰면 돼요.

## 소제목은 이렇게

- 목록은 이렇게
- **굵게**는 별표 두 개로
```

5. 오른쪽 위 **Commit changes**를 누르면 1~2분 뒤 홈페이지에 올라가요.

- `tags`에 `담노트`를 넣으면 담노트 창의 「업데이트 소식」에도 나와요. 태그가 없으면 `tags:` 줄을 지워도 돼요.
- 사진은 `images` 폴더에 올린 뒤 본문에 `![설명](/images/파일이름.png)`처럼 넣어요.
- 글을 고치거나 지우려면 `_posts`에서 그 파일을 열고 ✏️(고치기) 또는 ⋯ → Delete file을 눌러요.

## 파일 구성

- `index.html`: 바탕화면, 창, 시작 메뉴 (맨 위 `SITE` 설정에 링크 주소가 있어요)
- `_posts/`: 개발 일지 글
- `_guide/`: 담노트 사용 설명서 (파일 하나가 목차 한 칸이에요. `order` 숫자 순서로 나와요)
- `posts.json`, `guide.json`: 목록을 자동으로 만들어 주는 파일 (고치지 않아도 돼요)
- `_layouts/post.html`: 글 하나짜리 공유 링크를 바탕화면으로 연결해 줘요
