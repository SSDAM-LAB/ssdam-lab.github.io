## 새 메모 만들기

**＋ 새 메모**를 누르면 템플릿 목록이 나와요. 하나 고르면 정리용 칸이 미리 채워진 페이지가 열려요. 칸은 마음대로 고치거나 지워도 돼요.

| 템플릿 | 이런 걸 적어요 |
|---|---|
| 📝 빈 메모 | 메모장처럼 자유롭게 |
| 🔮 타로 정리 | 질문, 스프레드, 카드별 해석 (정·역방향) |
| 💖 덕질 일기 | 무대 기록, 오늘의 노래, 덕질 소비 |
| 🎬 감상 기록 | 영화·드라마·예능·음악, 회차 기록, 별점 |
| 📔 만년 다이어리 | 먼슬리, 위클리, 습관 체크, 프리메모 |
| ✅ To do list | 체크리스트, 우선순위 |
| 🌙 하루 일기 | 오늘의 기분과 감사한 일 |
| 📚 스터디 플래너 | 과목별 계획, 공부 시간 |
| 💼 업무일지 · 🗣 회의록 | 한 일, 진행 상태, 결정 사항 |
| 🔬 연구노트 | 목적, 방법, 결과, 고찰 |
| 🎯 만다라트 | 핵심 목표 1 · 세부 목표 8 · 실천 64 |
| 💰 가계부 | 수입·지출 자동 합계 |
| 🏋️ 운동 · ✈️ 여행 · 📖 독서 | 기록용 양식 |

## 내 템플릿 만들기

자주 쓰는 모양으로 양식을 고쳤다면 **⭐ 템플릿으로 저장**을 눌러요. 다음부터 **＋ 새 메모**의 **⭐ 내 템플릿**에서 고를 수 있어요.

## 글 꾸미기

툴바에서 제목, 굵게, 형광펜, 글자색, 체크리스트, 표, 인용, 박스를 쓸 수 있어요.

- 체크리스트는 네모 칸을 누르면 완료 표시가 돼요.
- 표에서 필요 없는 줄은 **－ 행**으로 지워요.
- 메모는 쓰는 동안 저절로 저장돼요. PC에서는 **Ctrl+S**로 바로 저장할 수도 있어요.
