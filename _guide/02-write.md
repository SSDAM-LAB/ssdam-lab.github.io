## 새 메모 만들기

**＋ 새 메모**를 누르면 템플릿을 고르는 창이 나와요. 위쪽 탭에서 **기본 · 공부 · 업무 · 생활 · 취미 · 덕질**로 나눠 볼 수 있어요. 하나 고르면 정리용 칸이 미리 채워진 페이지가 열리고, 칸은 마음대로 고치거나 지워도 돼요.

> 💡 처음이라면 **📔 만년 다이어리**, **🎬 감상 기록**, **💼 업무일지·🗣 회의록**, **💰 가계부**부터 써 보세요.

## 기본

| 템플릿 | 이런 걸 적어요 |
|---|---|
| 📝 빈 메모 | 메모장처럼 자유롭게 |
| ✅ To do list | 체크리스트, 우선순위 |
| 🌙 하루 일기 | 오늘의 기분과 감사한 일 |
| 📔 만년 다이어리 | 먼슬리, 위클리, 습관 체크, 프리메모 |

## 공부 · 업무

| 템플릿 | 이런 걸 적어요 |
|---|---|
| 📚 스터디 플래너 | 과목별 계획, 공부 시간, 피드백 |
| 💼 업무일지 | 오늘 한 일, 진행 상태, 내일 할 일 |
| 🔬 연구노트 | 목적, 방법, 결과, 고찰, 서명 |
| 🗣 회의록 | 안건, 논의, 결정, 액션 아이템 |
| 🎯 만다라트 | 핵심 목표 1 · 세부 목표 8 · 실천 64 |

## 생활

| 템플릿 | 이런 걸 적어요 |
|---|---|
| 💰 가계부 | 수입·지출 자동 합계 |
| 🏋️ 운동 기록 | 종목, 세트, 무게, 컨디션 |
| ✈️ 여행 계획 | 일정, 준비물, 예산 |
| 📖 독서 기록 | 별점, 인상 깊은 구절, 내 생각 |

## 취미 · 덕질

| 템플릿 | 이런 걸 적어요 |
|---|---|
| 🔮 타로 정리 | 질문, 스프레드, 카드별 해석 |
| 💖 덕질 일기 | 아이돌·음악, 무대 기록, 오늘의 노래, 덕질 소비 |
| 🎬 감상 기록 | 영화·드라마·예능·음악, 회차 기록, 별점 |

## ⭐ 내 템플릿

자주 쓰는 모양으로 양식을 고쳤다면 **⭐ 템플릿으로 저장**을 눌러요. 템플릿 창에 **⭐ 내 템플릿** 탭이 생기고, 다음부터 거기서 고를 수 있어요.

## 글 꾸미기

툴바에서 제목, 굵게, 형광펜, 글자색, 체크리스트, 표, 인용, 박스를 쓸 수 있어요.

- 체크리스트는 네모 칸을 누르면 완료 표시가 돼요.
- **🖍 형광펜**을 지우려면 칠한 곳에 커서를 두거나 글자를 선택하고 형광펜을 한 번 더 눌러요.
- 표는 커서가 있는 칸을 기준으로 **＋ 행 · － 행**(가로줄), **＋ 열 · － 열**(세로줄)을 늘리고 지울 수 있어요.
- 메모는 쓰는 동안 저절로 저장돼요. PC에서는 **Ctrl+S**로 바로 저장할 수도 있어요.
