## 앱처럼 설치하기

설치해 두면 바탕화면이나 홈 화면 아이콘으로 바로 열리고, 인터넷이 없어도 써져요.

**PC (크롬·엣지)**
- 주소창 오른쪽의 설치 아이콘(🖥⬇)을 눌러요.
- 또는 담노트의 **⚙️ 설정 → 앱 설치**를 눌러요.

**안드로이드 (크롬)**
- 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**를 눌러요.

**아이폰·아이패드**
- 꼭 **Safari**로 열어 주세요.
- 공유 버튼 ⬆️ → **홈 화면에 추가** → **추가**를 눌러요.

> 🍎 아이폰은 홈 화면에 추가한 앱과 Safari가 저장 공간을 따로 써요. 메모를 오래 안전하게 두려면 **홈 화면 앱으로만** 쓰는 걸 추천해요.

## 메뉴 찾기

- **PC**: 왼쪽 목록 맨 아래에 **🛟 사용자 지원**과 **⚙️ 설정**이 있어요.
- **휴대폰**: 왼쪽 위 **☰**를 누르면 같은 메뉴가 나와요.

## 내 메모는 어디에 저장되나요?

메모와 사진은 서버로 보내지 않고 **지금 쓰는 기기 안에만** 저장돼요. 그래서 다른 기기에서는 따로 옮기기 전까지 보이지 않아요. 옮기는 방법은 [다른 기기와 맞추기](#/guide/05-sync)에 있어요.
