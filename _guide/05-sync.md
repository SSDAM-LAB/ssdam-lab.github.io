PC와 휴대폰처럼 두 기기의 메모를 **숫자 6자리**로 합칠 수 있어요. 로그인도 파일도 필요 없어요. 서로 다른 메모는 둘 다 남고, 같은 메모는 더 최근에 고친 쪽으로 맞춰져요.

## 이렇게 해요

1. 두 기기에서 모두 담노트를 열어요.
2. 한쪽에서 **⚙️ 설정 → 다른 기기와 맞추기 → 내 코드 띄우기**를 눌러요. 숫자 6자리가 나와요.
3. 다른 쪽에서 **⚙️ 설정 → 다른 기기와 맞추기 → 코드 입력하기**를 누르고 그 숫자를 입력해요.
4. 두 기기에 **그림 3개**가 떠요. 서로 똑같은지 확인하고, 코드를 띄운 기기에서 **맞아요, 연결**을 눌러요.
5. 끝날 때까지 두 화면을 켜 둔 채 기다려요.

> 🔒 그림 3개가 다르면 누르지 말고 취소한 뒤 새 코드로 다시 해 주세요. 다른 기기가 끼어드는 걸 막는 확인 단계예요.

## 연결이 잘 안 될 때

- 두 기기 모두 화면이 꺼지지 않았는지 확인해요.
- 집 와이파이와 LTE처럼 서로 다른 인터넷에 있으면 **🔑 연결 키**가 필요할 수 있어요. 연결 키는 함께 쓰는 분들께 따로 알려 드려요. 한 기기에 넣어 두면 맞출 때 다른 기기에도 자동으로 옮겨가요.
- 그래도 안 되면 **연결이 안 될 때: 파일로 옮기기**를 눌러 백업 파일로 옮길 수 있어요. 카톡 「나와의 채팅」으로 파일을 보내서 다른 기기에서 **백업 불러오기**를 하면 돼요.
